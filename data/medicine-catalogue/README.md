# Generic reference candidates

This file contains 984 distinct name entries consolidated from a user-provided list of 1,000 numbered entries.

- `generic-reference-candidates.csv` preserves each supplied name and the original entry number(s) where it appeared.
- Repeated exact names are consolidated into one row; all original entry numbers are retained in the second column.
- These are unverified generic/reference-name candidates only. They are not a list of DDA-registered products, approved brands, available stock, or prescribing recommendations.
- No brand, strength, dosage form, manufacturer, registration number, or registration status is inferred from this file.
- Do not display these entries as purchasable medicines or use them to enable ordering until authoritative source verification, pharmacist review, and the required legal/regulatory checks are complete.
- The source was the user-provided 1,000-entry list; this file is not an official DDA export.

The original submitted list should be retained separately as source material. Any future corrections or classifications must preserve provenance and must not silently overwrite the original names.
